# Documentation

This directory contains documentation, website content, and media assets for ORGGML.

## Structure

- `website/` - Website content (from ggml-org.github.io)
- `media/` - Images, diagrams, and other media assets
- **[OPENCOG_COMPONENT_MAPPING.md](./OPENCOG_COMPONENT_MAPPING.md)** - Detailed mapping of ORGGML component groups to OpenCog cognitive architecture subsystems
- **[CI_WORKFLOW_MAPPING.md](./CI_WORKFLOW_MAPPING.md)** - CI/CD workflow architecture and component build ordering
- **[IMPLEMENTATION_SUMMARY.md](./IMPLEMENTATION_SUMMARY.md)** - Implementation status and summaries
