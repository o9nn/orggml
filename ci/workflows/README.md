# CI Workflows

GitHub Actions workflows for continuous integration across the ORGGML monorepo.

## Planned Workflows

- **Build**: Cross-platform builds (Linux, macOS, Windows)
- **Test**: Automated testing for all modules
- **Lint**: Code quality and style checks
- **Performance**: Benchmark regression detection
- **Release**: Automated release creation and deployment
